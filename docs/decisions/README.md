# Decisions

One file per decision. Numbered, dated, and not edited after the fact — if a
decision is reversed, write a new one that supersedes it and say so. The value
of this directory is that it records what was **rejected** and why; a future
reader can already see what was chosen by looking at the code.

Seven product directions died before this one. That is the reason this folder
exists: without it, the eighth conversation starts from scratch.
